# Crema Gazi Website

Premium React/TypeScript/Tailwind website for Crema Gazi, a 24hr delivery coffee, crepe, waffle and pastry shop in Gazi, Athens.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Playwright visual/behavior checks

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run test:e2e
```
